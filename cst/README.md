# CST-моделирование MIMO-решётки 8 Rx + 4 Tx (ДЗ2, этапы 2–3)

Проверка гипотез Г1 и Г2 из `HANDOFF_CST.md` в CST Studio Suite 2024 (TD-решатель, Python 3.9 + `cst.interface`).
Этап 4 (патчи на RO4003) **по решению пользователя не делался** (22.10.2026).

## Геометрия и настройки

* Rx: x = −105 … 105 мм, шаг 30 мм, y = 0; Tx: x = ±112,5 и ±127,5 мм, y = +30 мм. Все 12 диполей вдоль y, в плоскости z = 0.
* Дискретный порт 50 Ом в зазоре; порты 1–8 = Rx1…Rx8, 9–12 = Tx1…Tx4.
* Диапазон 9–11 ГГц, границы open + вакуумный запас 15–20 мм, мониторы ДН 9,8 / 10,0 / 10,2 ГГц.
* Этап 2: диполи 1,5 мм (λ/20), провод r = 0,1 мм, зазор 0,3 мм (точечные источники, ~300 тыс. ячеек, 5 с/порт).
* Этап 3: диполи 12,5 мм, r = 0,25 мм, зазор 0,5 мм (резонанс 10,19–10,30 ГГц, |S11| ≤ −13,8 дБ на 10 ГГц;
  ~500 тыс. ячеек, 20 с/порт). Для сравнения сохранён прогон с 13,6 мм (резонанс 9,2–9,5 ГГц) — `stage3_L13.6`.
* ДН каждого порта: Directivity, фаза от глобального нуля (`FarfieldPlot.Origin "zero"`), θ 0…180°, φ 0…359°, шаг 1°.
* Остальные порты при расчёте нагружены 50 Ом (это и есть «встроенная» ДН элемента).

## Методика оценки

`tools/phase_center_fit.py` (МНК по фазе, веса |E|²). Для диполя вдоль y берётся ко-поляризационная
компонента Людвига E_θ·sinφ + E_φ·cosφ — у отдельных E_θ, E_φ есть смена знака по φ, и фит срывается.

* Элемент и пара (произведение ДН): сектор ±30° вокруг нормали, фит x, y, z.
  Если остаток > 30° (изрезанная ДН крайнего элемента) — сектор 20°/15°.
* Подрешётка (синфазная сумма ДН) и её произведения: сектор ±3° (внутри главного лепестка — при шаге λ
  первый нуль на 7,2°, дальше смена знака), z фиксирован (в узком секторе не обусловлен).
* Гипотезы оцениваются по **x, y** (плоскость решётки). Смещение по z эквивалентно фазовой кривизне
  k·z·(1 − cosθ) и координатой решётки не исправляется.

## Этап 3 — полуволновые диполи 12,5 мм (слабая связь)

Фазовые центры на 10 ГГц (`stage3/phase_centers.md`):

| элемент | геометрия x, y | фит x, y | откл. x, y | фит z | φ0 отн. rx4 |
|---|---|---|---|---|---|
| rx1 / rx8 | ∓105; 0 | ∓105,16; 0,23 | 0,23 | −11,1 | −70,5° |
| rx2 / rx7 | ∓75; 0 | ∓75,21; 0,06 | 0,21 | −15,5 | −21,9° |
| rx3…rx6 | ∓45, ∓15; 0 | ±0,04; 0,01 | ≤ 0,04 | −17,4 | ≈ 0° |
| tx1 / tx4 | ∓127,5; 30 | ∓126,30; 30,31 | 1,20 | 1,6 | 159° |
| tx2 / tx3 | ∓112,5; 30 | ∓113,68; 29,48 | 1,18 | 4,6 | 125° |

В полосе 9,8–10,2 ГГц: Rx ≤ 0,7 мм, Tx ≤ 1,52 мм (на 10,2 ГГц).

* **Г2 (элемент):** для Rx (шаг λ) выполняется с запасом — ≤ 0,23 мм на 10 ГГц, ≤ 0,7 мм в полосе (λ/40).
  Для пар Tx (шаг λ/2) — на пределе: 1,2 мм на 10 ГГц, 1,5 мм на 10,2 ГГц (= λ/20). Диполи пары
  «расходятся» по x (взаимная связь), а по y смещаются на ∓0,5 мм.
* **Г1 (пара):** фазовый центр произведения ДН равен сумме фазовых центров с точностью ≤ 0,6 мм (λ/50)
  по x, y для пар и ≤ 0,01 мм для подрешёток. Выполняется.
* **Что не вписывается в модель ВАР:**
  1. **Разнофазность встроенных ДН.** У крайних Rx фаза φ0 отстаёт на 70°, у предпоследних на 22°, у Tx —
     на 125–159° относительно внутренних Rx. Это не смещение центра, а комплексный коэффициент элемента;
     без калибровки он действует как ошибка координаты: синфазная сумма rx1…rx4 даёт кажущийся центр
     −68 мм вместо −60 (на 10,2 ГГц −73,5). После калибровки по φ0 ВАР работает (см. Г1).
  2. **Фазовая кривизна (фит z = −11…−17 мм, остаток 5–10°).** Встроенная ДН диполя в ряду с нагруженными
     соседями не сферическая: рассеяние соседей даёт рябь фазы до ±10° в секторе ±30°. Координатами это не
     исправляется; для ОФН/обратных проекций в широком секторе нужна калибровка по углу (таблица ДН).
* **S-матрица** (`stage3/mimo_half.s12p`, `stage3/mimo_half_S.md`): |Sii| на 10 ГГц −13,8…−15,4 дБ;
  худшая развязка Tx–Rx −27,4 дБ (Tx2–Rx1, Tx3–Rx8 при сдвиге ряда Tx на y = λ), Rx–Rx −19,1 дБ (соседи, шаг λ).

Прогон с диполями 13,6 мм (резонанс 9,2–9,5 ГГц): те же выводы, смещения Tx 1,9–2,4 мм (> λ/20),
φ0 крайних Rx −53°: расстроенный элемент связан сильнее.

## Грабли CST 2024, найденные здесь

* `ASCIIExport` ДН в тихом режиме → «No plot data available for export». Работает только список точек
  `FarfieldPlot.AddListEvaluationPoint` + `CalculateList` + `GetList`.
* `CalculateList` после переоткрытия проекта → «Farfield: No HEX mesh found» (в `Result\Model.log`).
  ДН считается только в сессии, где решатель отработал (сетка в памяти). Поэтому экспорт — в том же скрипте.
* Ключи `GetList`: `"Spherical linear theta abs"`, `"... theta phase"`, `"... phi abs"`, `"... phi phase"`;
  без `linear` — «Invalid field component». `"Spherical abs"`, `"Point_T"`, `"Point_P"` — как есть.
* `FarfieldPlot.SetPolarizationType "Spherical"` — «Illegal polarization type»; просто не вызывать.
* Touchstone: объект `TOUCHSTONE` с методом `.Write` (не `.Execute`).
* `GetList` в русской локали отдаёт числа с запятой — заменять на точку.
* Заголовок для `phase_center_fit.py`: имена колонок без двойных пробелов внутри (парсер делит по 2+ пробелам).
